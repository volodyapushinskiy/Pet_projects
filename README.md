# ML / DL / NLP Projects

Подборка из **4 практических pet-проектов** по машинному обучению, deep learning и NLP.  
Репозиторий собран как компактное портфолио задач из реального ML-стека: **классификация текста, трансформеры, spam-detection и регрессия**.

---

## Что внутри

### `Orders_review`
**Анализ тональности отзывов покупателей** на датасете Brazilian E-Commerce от Olist.

В проекте показан полный NLP-пайплайн: от очистки текста и подготовки целевой переменной до обучения модели, которая определяет тональность отзыва как **negative / neutral / positive**.  
Используются подходы на базе **FastText, BERT, Logistic Regression и CatBoost**.

### `Transformer_classification`
**Классификация тональности предложений** с помощью **DistilBERT** и библиотеки **Hugging Face Transformers**.

Проект демонстрирует работу с предобученным трансформером для бинарной классификации текста: **positive / negative**.  
Фокус — на современном DL/NLP-подходе, использовании `pipeline` и сравнении результатов на двух датасетах.

### `Email_classification`
**Классификация писем на spam / non-spam**.

Практический ML/NLP-проект, где текст писем проходит предобработку, преобразуется в признаки через **Bag of Words**, а затем подаётся в несколько моделей классификации.  
Проект хорошо показывает классический pipeline для задачи фильтрации спама и сравнение качества разных алгоритмов.

### `Laptop_prices_prediction`
**Предсказание цены ноутбука** по техническим характеристикам.

Регрессионный проект с акцентом на подготовку табличных данных, обработку выбросов, подбор признаков и обучение моделей для прогноза стоимости.  
Итог — модель, способная оценивать цену новых конфигураций ноутбуков на основе их параметров.

## Почему репозиторий выглядит сильно

- охватывает сразу несколько направлений: **ML, DL и NLP**;
- сочетает **классические алгоритмы** и **современные transformer-подходы**;
- включает как **текстовые задачи**, так и **регрессию на табличных данных**;
- показывает не только обучение моделей, но и полноценный пайплайн: **предобработка, обучение, оценка и анализ результата**.
